Troubleshooting

If you encounter issues with this dashboard:

  1. Make sure you have run pnpm test:cov to generate coverage reports
  2. For viewing existing reports without regenerating, use pnpm test:cov:view
  3. Check the debug information below for loading errors
  4. If needed, manually run individual test types: pnpm test:unit:cov, pnpm test:integration:cov, pnpm test:e2e:cov
